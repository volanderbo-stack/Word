# Слово

Тренажер ораторського мистецтва українською: голос і дикція, логіка мовлення, поезія класиків, особистий словник.
Чистий HTML/CSS/JS, без бекенду і залежностей. Працює офлайн як PWA.

## Запуск

Застосунок треба відкривати через локальний сервер: мікрофон, service worker і ES-модулі не працюють, якщо відкрити `index.html` як файл.

Найпростіше (потрібен лише Node.js):

```bash
node server.mjs
```

Потім відкрийте http://localhost:5173. Інший порт: `node server.mjs 8080`.

Альтернатива: `npx serve .`.

### На телефоні

Браузер дає доступ до мікрофона лише на `https://` або `localhost`. Щоб користуватися на телефоні, розмістіть папку на будь-якому статичному хостингу з https (GitHub Pages, Netlify, Cloudflare Pages), відкрийте адресу і виберіть «Додати на головний екран».

## Структура

```
index.html              каркас сторінки
manifest.webmanifest    налаштування PWA
sw.js                   офлайн-кеш
server.mjs              локальний сервер для розробки
css/styles.css          стилі, світла й темна теми
js/app.js               вкладки, тема, реєстрація service worker
js/state.js             прогрес, XP, рівні, серія днів (localStorage, ключ slovo:v1)
js/db.js                аудіозаписи (IndexedDB)
js/recorder.js          запис голосу і повідомлення про помилки мікрофона
js/badges.js            досягнення (бейджі) і їх перевірка після кожної зміни прогресу
js/charts.js            SVG-графік самооцінок (кольори ліній перевірені на дальтонізм)
js/srs.js               особистий словник, інтервальне повторення (Лейтнер)
js/ui.js                спільні елементи: іконки, тости, форматування
js/widgets.js           віджети вправ: виступ із таймером і записом, дихання,
                        скоромовка, вірш, самооцінка, список записів
js/views/*.js           п'ять вкладок (підшляхи: #/today/warmup, #/voice/breath/478 тощо)
data/content.js         увесь контент
icons/                  іконки застосунку
```

## Як доповнювати контент

Усе в `data/content.js`. Над кожним масивом є коментар із форматом запису: скопіюйте сусідній об'єкт і змініть текст.

Правила для віршів:

- Повний текст можна додавати лише для авторів, які померли понад 70 років тому (суспільне надбання): Шевченко, Леся Українка, Франко, Олесь, Глібов, Руданський, Грабовський, Вороний, Антонич, Зеров, Свідзінський тощо.
- Рильський, Тичина, Стус, Костенко, Симоненко та інші автори, чиї тексти ще захищені, — лише в `linkedPoems`: автор, назва, посилання.
- Кожен текст звіряйте з першоджерелом і вказуйте посилання в полі `source`.
- Зараз повний текст мають 12 віршів. Ще кілька класичних (Шевченко «Сонце заходить, гори чорніють», Леся Українка «Надія» тощо) стоять у `linkedPoems` лише посиланням: їх треба звірити з першоджерелом і перенести в `poems`.

Після додавання нового **файлу** (не контенту) впишіть його в список `ASSETS` у `sw.js` і збільште `VERSION`, щоб він працював офлайн.

## Дані користувача

- Прогрес і налаштування: `localStorage`, ключ `slovo:v1`. Поле `version` і `MIGRATIONS` у `js/state.js` — для майбутніх змін формату.
- Записи голосу: IndexedDB, база `slovo`, сховище `recordings`.

Усе зберігається лише в цьому браузері на цьому пристрої.
